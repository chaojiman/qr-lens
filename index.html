1. Overview / 概述

QR Lens ("the Extension", "we", "our") is a lightweight Chrome browser extension developed to recognize QR codes from images on web pages and local files upon user mouse hover. We are fully committed to protecting your privacy and personal data. QR Lens（“本扩展程序”或“我们”）是一款轻量级的 Chrome 浏览器扩展，用于在用户鼠标悬停时识别网页和本地文件中的二维码图片。我们严格遵守隐私合规要求，全力保护您的个人隐私与数据安全。

2. Zero User Data Collection / 零用户数据收集承诺

Strict Zero-Log & Local Processing Policy / 严格的零日志与纯本地运行政策

The Extension does NOT collect, transmit, store, sell, or share any personally identifiable information (PII) or user browsing data. 本扩展程序绝不收集、不传输、不存储、不出售、不共享任何个人身份信息（PII）或用户浏览行为数据。

Specifically, QR Lens DOES NOT collect:

  • No Personal Information: Names, email addresses, phone numbers, credentials, or accounts.
  • No Browsing Activity: URLs visited, webpage history, clicks, search queries, or form inputs.
  • No Device or Network Identifiers: IP addresses, MAC addresses, device fingerprints, or location data.
  • No Remote Image Data: Scanned images and decoded QR results never leave your browser.

3. 100% Local Offline Processing / 100% 本地离线处理

All image analysis, QR code detection, and decoding routines are executed 100% locally and offline on your machine using built-in web technologies (Offscreen Canvas / Web Worker). 所有的图像分析、二维码识别与解码全部在您的计算机本地离线完成，绝不会将图片或解码内容上传到任何远程服务器或云端服务。

4. Permissions Justification / 权限使用声明

QR Lens requests only the minimum set of permissions necessary to function properly:

Permission / 权限 Purpose / 作用说明 Scope & Data Handling / 范围与处理方式
storage Used strictly to save user preferences (e.g. hover trigger delay, sound/preview switch) and optional short-term local scan history (up to 15 records). Saved 100% locally on the user device via Chrome Storage API. Automatically purges history records older than 3 days. Never synchronized to remote servers.

5. Third-Party Services & Remote Code / 第三方服务与远程代码

QR Lens does NOT embed any third-party tracking scripts, analytics SDKs (such as Google Analytics), advertisement networks, or external API endpoints. The extension contains NO remote executable code; all code is bundled within the signed extension package. 本扩展程序不包含任何第三方跟踪器、分析探针或广告网络，也不包含任何远程执行代码，所有代码均封装在已签名的扩展安装包内。

Should any feature updates require modifications to this Privacy Policy, the revised policy will be posted on this page with an updated revision date. 如果未来功能变动涉及隐私条款调整，我们将在此页面上公开发布最新版本并更新生效日期。
